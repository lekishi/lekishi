== Make the map worth looking at

- [ ] Ship a self-made relief basemap (hypsometric tint, shaded relief, coastlines, rivers) as static tiles: zoom 0–4 global, 0–7 over chapter extents, provider-free (RFD 3 owns the tiling).
- [ ] Collision-free labels: one per place, event-count badge, zoom priority, CJK-capable fonts, historical name leading with local script and romanization.
- [ ] Places-first markers: events attach to places, a place with many events shows a count and opens a list.
- [ ] Short event titles; caveats, precision, and placement notes move to the card.
- [ ] Schematic journey lines through dated stops, labelled schematic, animated with the playhead.
- [ ] Relationship arcs on selection, styled by type, with the claim and citation reachable from the arc.
- [ ] Dated control-snapshot polygons with a hatched edge and a date label; no interpolation.
- [ ] Timeline strip with event ticks, window brush, playhead, and zoomable scale; retire the number inputs.
- [ ] Chrome diet: one header line, an About sheet for editorial status and coverage, a narrative-and-image-first selection card.
- [ ] Nearby and connected lists in the card, kept separate.
- [ ] Layer controls for story layers; shared window and playhead; non-colour membership cues.
- [ ] Coverage guidance with distinct uncovered and filtered-empty states.
- [ ] Reduced-motion preference respected for playback and camera flights.
- [ ] Exit review: the served Tang chapter beside its hero, judged by the owner.
