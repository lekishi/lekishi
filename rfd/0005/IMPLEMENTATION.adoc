= RFD 0005 implementation checklist

Implements link:README.adoc[RFD 5: Design system and layout]. The RFD is in
`discussion`. The owner answered its open questions, and on 2026-10-13 asked
for the design system itself (reference document, tokens, primitives, living
page) in the RFD's pull request, so the Foundation started before the sheet's
formal approval; that approval stays open below. Each step after the sheet lands
something a reader can see, and the RFD 1 checklist items it serves are named
so the two checklists do not double-count.

== Navigation

- [ ] The URL contract: pure parse and write functions beside `state.ts` for `event`, `place`, `step`, `from` and `to`, with unit tests for precedence, the default window and stale ids; the workspace applies them, adding a history entry for jumps and replacing it for in-chapter changes.
- [ ] The search index: one static file built from the published records (every name form, romanization and story caption), a build-invariant check that it covers every served chapter, and its size recorded against RFD 4 RC4.
- [ ] `SearchDialog`: opened by `/` and the `DateBar` control on every page, results grouped by chapter with the current one first, a scope toggle, a preview, and keyboard operation; the left rail's event search reuses it with the scope fixed.
- [ ] Chapter switcher from the chapter name in the `DateBar`, with the time ribbon and this device's last position per chapter.
- [ ] Arrival plate for a linked event ("Play from here", "From the beginning") and the not-found line for a stale id.
- [ ] Home: search first, chapters on the globe and the time ribbon, "Continue where you left off" from browser storage; the not-found page keeps search and the chapter list.
- [ ] Browser checks: a linked event opens its card, Back after a search jump returns to the origin, and search is reachable by keyboard alone (RC4).
